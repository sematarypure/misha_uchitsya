# Памятка к уроку 01

## Что ставим

1. [Git for Windows](https://git-scm.com/install/windows) — программа для истории изменений. После установки открой новый PowerShell и набери `git --version`.
2. [Visual Studio Community](https://visualstudio.microsoft.com/downloads/) — IDE. В установщике отметь **.NET desktop development**. Это даст шаблон консольного приложения и .NET SDK.
3. [GitHub](https://docs.github.com/en/account-and-profile/how-tos/account-management/creating-an-account-on-github) — создай личный аккаунт, подтверди email. GitHub понадобится для хранения проекта онлайн.

Если `dotnet --version` не показывает версию после установки Visual Studio, перезапусти терминал. Если всё ещё не работает, проверь установленный SDK по [инструкции Microsoft](https://learn.microsoft.com/en-us/dotnet/core/install/windows). Нужен **SDK**, не только Runtime.

## Первые команды Git

Открой терминал **в корне своего проекта**. В строках ниже впиши свои имя и email; кавычки вокруг имени оставь.

```powershell
git config --global user.name "Твоё имя"
git config --global user.email "твоя-почта@example.com"
git --version
git init -b main
git status
git add .
git commit -m "Первый запуск"
git status
```

Перед `git add .` создай `.gitignore`:

```gitignore
bin/
obj/
.vs/
```

Если репозиторий уже создан через Visual Studio, **не выполняй `git init` повторно**. Сначала проверь `git status`.

## Публикация на GitHub

Создай **пустой** репозиторий `TaskBoard`: не добавляй README и .gitignore на сайте, потому что проект уже есть на компьютере. Скопируй адрес HTTPS, затем в терминале проекта:

```powershell
git remote add origin <адрес-из-GitHub>
git push -u origin main
```

GitHub может открыть окно входа в браузере. Пароль или код подтверждения никому не отправляй.

## Запомни

- `Program.cs` — текст программы.
- `.csproj` — файл настроек проекта.
- `Console.WriteLine("Привет!");` — показать текст в консоли.
- `Ctrl+F5` — запустить без отладки в Visual Studio.
- `git commit` сохраняет версию локально; `git push` отправляет её на GitHub.
