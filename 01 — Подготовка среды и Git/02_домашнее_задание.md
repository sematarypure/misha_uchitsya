# Домашнее задание 01. Среда работает

**Время:** 30–60 минут, в зависимости от установки. Сделай сам; при проблеме запиши точный текст ошибки или скриншот и шаг, на котором остановился.

## Обязательно

1. Убедись, что установлен Git и Visual Studio Community с нагрузкой **.NET desktop development**. В PowerShell проверь `git --version` и `dotnet --version`.
2. Создай или открой проект `TaskBoard` в отдельной папке для кода. Запусти и измени `Program.cs` так, чтобы выводились **три разные строки**: приветствие, твоё имя/псевдоним и фраза о том, что ты хочешь сделать.
3. Проверь `git status`. Если репозитория ещё нет, создай его. Добавь `.gitignore` для `bin/`, `obj/` и `.vs/`, затем сделай коммит с понятным сообщением.
4. Создай аккаунт GitHub и подтверди почту. Создай **пустой приватный** репозиторий `TaskBoard` и опубликуй свой локальный проект. Инструкции: [GitHub](https://docs.github.com/en/migrations/importing-source-code/using-the-command-line-to-import-source-code/adding-locally-hosted-code-to-github). Если `push` не сработал, пришли преподавателю сообщение ошибки, а не пароль.

## Готово, когда

- `Ctrl+F5` показывает твои три строки.
- `git status` после коммита сообщает, что рабочее дерево чистое.
- На GitHub видны `Program.cs`, `.csproj` и `.gitignore`; папок `bin/`, `obj/` нет.
- Ты можешь в двух фразах объяснить разницу между Git и GitHub.

**Дополнительно:** измени одну строку ещё раз и сделай второй коммит. Посмотри историю через `git log --oneline`.

**Что прислать:** ссылку на репозиторий (или пригласить преподавателя, если он приватный), плюс один вопрос, который возник.
