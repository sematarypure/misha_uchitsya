# Памятка к уроку 02

## Три части маленькой программы

1. **Ввод:** программа получает текст от пользователя через `Console.ReadLine()`.
2. **Обработка:** хранит данные в переменных, объединяет текст, считает `age + 1`.
3. **Вывод:** показывает результат через `Console.WriteLine(...)`.

Код выполняется сверху вниз. Посмотри на каждую строку и попробуй заранее сказать, что увидишь в консоли.

## Минимальный словарь

| Запись | Что означает |
| --- | --- |
| `string name = "Аня";` | Создать текстовую переменную `name` и записать значение |
| `int age = 20;` | Создать переменную для целого числа |
| `Console.Write("Имя? ");` | Написать текст без перехода на новую строку |
| `Console.ReadLine()` | Прочитать строку, введённую человеком |
| `Console.WriteLine($"Привет, {name}!");` | Вывести строку с подставленным значением |
| `age + 1` | Сложить числа; строка `"20"` числом не является |

`;` завершает инструкцию. Имена в C# чувствительны к регистру. Если программа не собирается, читай текст ошибки и номер строки. Проверяй одну вещь за раз.

## Самопроверка

Что выведет этот код? Сначала ответь, затем запусти:

```csharp
string name = "Саша";
int count = 2;
Console.WriteLine($"Привет, {name}!");
Console.WriteLine(count + 1);
```

Ожидается `Привет, Саша!` и `3` на разных строках. Если вышло иначе, перечитай строки по порядку.
