# Домашнее задание 02. Консольная визитка

**Время:** 35–60 минут. Меняй текущий проект `TaskBoard`; новый проект создавать не нужно.

## Задача

Напиши программу, которая:

1. Спрашивает имя и любимое занятие двумя отдельными вопросами.
2. Сохраняет ответы в переменных `string`.
3. Хранит выбранный тобой возраст в переменной `int` (пока прямо в коде).
4. Выводит три осмысленные строки: приветствие, любимое занятие и возраст через год. В одной из строк используй `$"..."`.
5. Делаешь коммит с сообщением вроде `Добавил консольную визитку` и отправляешь его на GitHub.

Пример результата (твои данные будут другими):

```text
Как тебя зовут? Миша
Что тебе нравится? Игры
Привет, Миша!
Тебе нравится: Игры
Через год тебе будет 21.
```

## Критерии готовности

- После запуска программа ждёт **два** ответа и показывает правильный текст.
- Если поменять значение `age`, вычисленный возраст тоже меняется.
- В `Program.cs` нет скопированного готового решения из памятки: ты можешь объяснить каждую строку.
- Последний коммит виден в истории Git/GitHub.

**Подсказка:** `Console.Write` оставляет курсор в той же строке; `Console.WriteLine` переводит на следующую. `Console.ReadLine() ?? ""` сохраняет введённый текст или пустую строку при отсутствии ввода.

**Дополнительно:** спроси ещё про любимый язык программирования и добавь строку ответа. Числовой возраст с клавиатуры пока не читай: этим займёмся в уроке 03.

**Что прислать:** ссылку на коммит и 1–2 предложения: что было понятно, где пришлось искать ошибку.
